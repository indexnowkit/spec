# 41. Go: модуль `github.com/indexnowkit/indexnow-go`

Go ≥ 1.22. Только stdlib в корне модуля. Подпакеты с внешними зависимостями:
`gorm`, `ent`, `httpkey` (только `net/http`), `chi`/`gin`/`echo` не нужны (httpkey даёт `http.Handler`).

## Core (`indexnow`)

```go
c, err := indexnow.New(indexnow.Config{Key: os.Getenv("INDEXNOW_KEY"), BaseURL: "https://www.example.com"})
results, err := c.Submit(ctx, []string{"/posts/a"})
```

- `Config` struct с теми же полями, что в 02 (`Engines []Engine`, `Debounce`, `Throttle`,
  `HTTPClient *http.Client`, `Logger *slog.Logger`, `DryRun`).
- `indexnow.GenerateKey()`, `indexnow.ValidateKey(string) error`.
- `Result` struct как в 02. `Submit` возвращает `error` только для программных ошибок
  (пустой список, невалидный URL); HTTP-исходы в `[]Result`.
- Debounce: `DebounceStore` interface, `MemoryStore` (map + mutex + TTL), Redis не в core
  (пример в README через `go-redis`).
- Dispatcher: `Dispatcher` interface; `SyncDispatcher`; `BatchDispatcher` (буферизованный
  канал, одна goroutine, flush по `MaxBatch` или `FlushInterval`, `Close(ctx)` для graceful
  shutdown, обязателен вызов в `defer`/`signal.NotifyContext`).
- Sitemap: `indexnow.SitemapURLs(ctx, url) ([]string, error)`.

## Объявление модели

Интерфейс:

```go
type URLProvider interface { IndexNowURLs() []string }
type Publishable interface { IndexNowPublished() bool }   // опционально
```

## `gorm` подпакет и commit-safety

- GORM-хуки `AfterCreate/AfterUpdate/AfterDelete(tx *gorm.DB)` выполняются **внутри**
  транзакции. Поэтому плагин `gormindexnow.Plugin{Client}` регистрируется через
  `db.Use(...)` и:
  1. на callbacks `gorm:after_create|after_update|after_delete` собирает URL объектов,
     реализующих `URLProvider`, в staging, привязанный к `*gorm.DB` транзакции
     (`tx.Statement.Context` + `sync.Map` по указателю `tx.Statement.ConnPool`; если
     ConnPool не `*sql.Tx`, значит autocommit, шлём сразу через dispatcher);
  2. оборачивает `db.Transaction(fn)`: экспортируется `gormindexnow.Transaction(db, fn)`,
     который после успешного `fn` делает flush staging, при ошибке отбрасывает. Для
     ручных `db.Begin()/Commit()` документируется `gormindexnow.Flush(tx)` после Commit.
  Это лучшее достижимое без outbox. Outbox-режим (`Plugin{Outbox: true}`) пишет URL в
  таблицу `indexnow_outbox` той же транзакцией, отдельный `OutboxWorker` отправляет.
- Delete: URL до удаления — в `BeforeDelete` хук объект ещё загружен; плагин читает
  `tx.Statement.Dest`.
- `Updates`/`UpdateColumn` с map не загружают модель, хуки срабатывают, но `Dest` может
  быть map: документировано, поддержка только struct-моделей.

## `ent` подпакет

- `ent` даёт `tx.OnCommit(func(next ent.Committer) ent.Committer)` — нативный после-commit
  хук. Подпакет генерирует helper `entindexnow.Hook(client, urlOf func(ent.Mutation) []string)`
  для `schema.Hooks()` с `hook.On(fn, ent.OpCreate|ent.OpUpdateOne|ent.OpDeleteOne)`:
  внутри транзакции URL складываются, `OnCommit` шлёт; вне транзакции сразу.
- `OpUpdate`/`OpDelete` (bulk без сущности) документированы как не поддерживаемые.

## `httpkey`

`httpkey.Handler(keyProvider) http.Handler`: `GET /{key}.txt` → 200 text/plain или 404.
Примеры монтирования для net/http, chi, gin (`gin.WrapH`), echo (`echo.WrapHandler`).
